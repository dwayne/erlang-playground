# Erlang Playground

A playground for me to explore and learn [Erlang](https://www.erlang.org/).

## Usage

You'll need [Nix](https://zero-to-nix.com/start/install/) with flakes enabled.

```bash
nix develop
erl # Erlang/OTP 29.0.6
```
